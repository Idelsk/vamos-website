# Anpassung Bilderseite und Lager 2027

Enthalten:

- `bilder.html`
- `lager2027.html`
- `css/unterseiten.css`

Änderungen:

- Die Flaggen auf der Bilderseite stehen auf großen Bildschirmen kompakt rechts im Hero.
- Dadurch werden sie nicht mehr unten abgeschnitten.
- Auf Mobilgeräten stehen die Flaggen wieder normal unter dem Text.
- Der Informationsbalken unter dem Hero von Lager 2027 ist deutlich flacher.
- Der Zeitraum wird kompakt als `10.07.–24.07.2027` angezeigt.
- Der Anmeldestart ist als eigener, klarer Datumsblock formatiert.

Einbau:

1. `bilder.html` ersetzen.
2. `lager2027.html` ersetzen.
3. `css/unterseiten.css` ersetzen.
